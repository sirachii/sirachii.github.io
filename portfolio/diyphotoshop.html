A Burst of Emotions

open DIY photoshop project

this is an interactive art project created using p5.js. i wanted to portray different visual effects and explore creativity through digital marks ranging from structured to chaotic forms.

users can draw using different tools and effects by pressing keys 1–0.

controls:

1–0 = drawing tools
G = place image
X = clear canvas
P = save artwork

code


var img;
var initials ='na';
var choice = '1';
var screenbg = 0;
var lastscreenshot = 61;

function preload() {
  img = loadImage('https://dma-git.github.io/images/74.png');
}

function setup() {
  createCanvas(606, 606);
  background(screenbg);
}

function draw() {

  if (keyIsPressed) {
    choice = key;
    clear_print();
  }

  if (mouseIsPressed){
    newkeyChoice(choice);
  }

  noStroke();
  fill(255);
  textSize(12);
  textAlign(CENTER);

  text("1-0 tools | G image | X clear | P save", width/2, 20);
}
