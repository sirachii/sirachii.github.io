A Burst of Emotions

open DIY photoshop project

This is an interactive p5.js drawing project exploring emotion through layered visual effects. It shifts between controlled structure and chaotic expression.

Users can create drawings using different tools by pressing keys 1–0, allowing experimentation with texture, motion, and randomness.

controls:

1–0 = tools
G = place image
X = clear canvas
P = save artwork
